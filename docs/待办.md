## 二、待办（按优先级）

### 1. 3D 视角可调（P2）
现在是常量 `AX/AY`（左前上方固定视角）。拖动旋转能让"被柱子挡住的那根"露出来，
但会带来两个必须一起解决的问题：① 360° 旋转时的**遮挡重排**（画家算法要按 z 重排，不是固定顺序）；
② 旋转后**文字朝向**（标签要不要跟着转）。
若不解决这两点，宁可不做——半成品旋转比固定视角更难读。

## 三、本轮定下的口径（改动前先读）

1. **不引 three.js / echarts-gl**：硬线是运行时零外部请求、体积可控；3D 只需要"投影 + 明暗"。
2. **3D 是视图，不是另一套数据**：取值范围、0 基线、合计、单位、空数据提示与 2D 完全一致；
   判据里有一条专门守这个（同数据分别渲染，逐项比口径）。
3. **明暗规则只有一处**：正面原色 / 侧面乘 0.72 / 顶面朝白插值 1.18；
   提亮不用"乘系数"（深蓝乘 1.2 会溢出、色相跑掉）。
4. **深度不参与读数**：z 只用于"分层/遮挡"，任何数值都必须能只靠柱高或扇角读出来。
5. **饼的侧壁只画朝前那半个圆周**：背面侧壁被自身顶面挡住，画了会在上沿露出"假厚度"。
