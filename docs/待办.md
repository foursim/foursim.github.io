## 三、定下的口径（改动前先读）

1. **运行时零外部请求**：不引 three.js 的 CDN 版本、不引渲染库（3D 图表是自算投影，3D 场景是本地 vendor）。
2. **三层结构**：根（总导航）→ 模块（`agri/` `web3d/`）→ 页面；**模块内自包含**（js/data/img/vendor 都在模块里）。
3. **一份事实只写一处**：配色令牌在 `tokens.css`；表格标题/口径由 `buildChartData` 给；聚合口径是 `AGG_RULE`。
4. **3D 是视图，不是另一套数据**：取值范围、0 基线、合计、单位、空数据提示与 2D 完全一致（判据守）。
5. **明暗规则只有一处**：正面原色 / 侧面 ×0.72 / 顶面朝白插值 1.18（乘系数会让深蓝溢出、色相跑掉）。
6. **深度不参与读数**：z 只用于分层与遮挡，任何数值都必须能只靠柱高或扇角读出来。
7. **饼的侧壁只画朝前那半个圆周**：背面侧壁被自身顶面挡住，画了会在上沿露出"假厚度"。
