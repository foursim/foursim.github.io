# 五分钟上手

> 这页是「动手」：想做的事 → 敲什么。**为什么这么做**看 `README.md`（长，别从头读；按目录挑）。

## 0. 这是什么

站点是**总导航 + 两个模块**：`index.html`（总导航）→ `agri/`（农业 GIS 数据模拟）或 `web3d/`（Web 3D 渲染）。

- **农业模块**：一块 6.9 km² 的地（501 个地块 / 62 个经营单元），由**确定性模型**生成 549 天的农事数据；
  `agri/index.html` 是模块导览页，`agri/sim.html` 是模拟主页面；
- **3D 模块**：`web3d/index.html` 是模块导航页，`web3d/wild6.html` 是全屏 3D 场景（three.js 已本地内置）；
- **页面**：纯静态，零外部依赖、不联网；
- **数据**：`tables/*.csv`（16 张表，另有一张按需导出的「地块 × 日」长表）+ Excel 合集 + `agri/data/*.json`（页面用）；
- **断言**：全部是**能失败**的判据（不是"看起来对"）。

## 1. 只想看页面

打开站点（或双击 `index.html`）→ 总导航页 → 进「农业 GIS」→ 导览页 → 点「打开模拟地图」进 `agri/sim.html`；
或进「Web 3D」→ 点「打开 demo」看全屏场景。

> ⚠️ **3D 场景必须走 HTTP**：它用 ES 模块 + WebGL，`file://` 下浏览器会把模块当跨源请求拦掉，
> 双击打开只会看到提示卡（说明原因与命令），不是白屏。农业模块的模拟页同理（需要 `fetch` 数据）。

若浏览器限制本地 `fetch`：

```bash
python -m http.server 8000     # 然后访问 http://localhost:8000
```

### 看 3D 图表

底部条或右侧「数据视图」切到**图表**页签 → 勾选「**3D 视图**」。
柱 / 饼 / 折线 / 雷达四张图一起换成立体投影；开关会记住（`localStorage`）。
**只换画法，取值范围与合计不变** —— 觉得"切了 3D 数字是不是变了"，切回 2D 对比即可（像素级还原）。

## 2. 查一个数

```bash
npm run query -- --only q14    # 只跑 q14（秒级，跳过判据）——改查询时的调试循环
npm run query -- --deps        # 15 个查询各读了哪些表、哪些列（运行时追踪）
npm run query                  # 全量查询 + 22 条判据
```

产物在 `tables/query/`：每个查询一份 CSV，外加一份可读的 Markdown 汇总。

## 3. 改页面 / 改代码

```bash
npm run ready          # 113 条 / 约 32 秒：模型冒烟 + 页面冒烟 + 查询 + 仓库卫生
npm run test:browser   # 237 条 / 约 150 秒：真浏览器，出截图
```

**改完先跑 `ready`**。它绿了再说"改好了"。`ready` 里包含页面冒烟（约 7 秒），
专门抓"页面根本起不来"这类故障（它真的抓到过：改坏一个方法名 ⇒ 页面白屏）。

## 4. 交付

```bash
npm run deliver                # tables/交付清单.md：必带 12 张 / 按需 1 张 / 说明 4 张
npm run pack -- --zip          # dist/agri-deliver-<日期>/ 与 .zip（约 6.3 MB）
npm run pack -- --smoke        # 打完再对着**包目录**跑冒烟（证明"打开是好的"）
```

包内包含：总导航页 + `agri/`（页面 + `data/*` JSON/GeoJSON）+ `web3d/`（含内置 three）+ 必带/说明表 + `交付清单.md` + `数据字典.md` + Excel。

## 5. 出问题了怎么办

| 症状 | 先跑这条 | 它会告诉你 |
|---|---|---|
| 页面白屏 / 起不来 | `npm run smoke:browser` | 页面自己的报错（7 秒） |
| 数字对不上 | `npm run data:check` | 25 条数据判据，逐项给差额 |
| 全量数据要重算 | `npm run data:all` | 从取数到交付（**需要联网**） |
| 不确定改了哪些表 | `npm run query -- --deps` | 表 + 列的运行时依赖 |

## 6. 目录

```
index.html        总导航（三个层次：总导航 → 模块导航 → 页面）
tokens.css        配色令牌（三层共用，改色只改这里）
hub.css           总导航与模块导航的样式
agri/             农业模块：index.html / sim.html / js / data / img / vendor(leaflet)
web3d/            3D 模块：index.html / wild6.html / vendor/three（r160，本地内置）
tools/            离线工具与判据（每个 *.mjs 都是一条命令）
tables/           交付数据（CSV + Excel + 查询产物）
docs/             这页
```

## 7. 三条纪律（踩过的坑）

1. **别为了让判据变绿而改判据**：判据红了先问"数据/代码是不是真错了"；
2. **页面报错要能看到**：`smoke:browser` 已经把 `Runtime.exceptionThrown` / `console.error` 接住了，
   超时信息里会带最近 4 条页面报错 —— 别只看"超时"两个字；
3. **一份事实只写一处**：分组规则（`tools/lib/deliver-groups.mjs`）、图表标题（`buildChartData`）、
   聚合口径（`AGG_RULE`）都是"改一处、处处一致"。
