# 五分钟上手

> 这页是「动手」：想做的事 → 敲什么。**为什么这么做**看 `README.md`（长，别从头读；按目录挑）。

## 0. 这是什么

一块 6.9 km² 的地（501 个地块 / 62 个经营单元），由**确定性模型**生成 549 天的农事数据：

- **页面**：纯静态，双击 `index.html` 就能看（零外部依赖、不联网）；
- **数据**：`tables/*.csv`（18 张表）+ Excel 合集 + `data/*.json`（页面用）；
- **断言**：全部是**能失败**的判据（不是"看起来对"）。

## 1. 只想看页面

双击 `guide.html`（导览页：这份数据是什么、怎么用），或直接双击 `index.html`（模拟主页面）。

若浏览器限制本地 `fetch`：

```bash
python -m http.server 8000     # 然后访问 http://localhost:8000
```

## 2. 查一个数

```bash
npm run query -- --only q14    # 只跑 q14（秒级，跳过判据）——改查询时的调试循环
npm run query -- --deps        # 15 个查询各读了哪些表、哪些列（运行时追踪）
npm run query                  # 全量查询 + 22 条判据
```

产物在 `tables/query/`：每个查询一份 CSV，外加一份可读的 Markdown 汇总。

## 3. 改页面 / 改代码

```bash
npm run ready          # 106 条 / 约 27 秒：模型冒烟 + 页面冒烟 + 查询 + 仓库卫生
npm run test:browser   # 216 条 / 约 90 秒：真浏览器，出截图
```

**改完先跑 `ready`**。它绿了再说"改好了"。`ready` 里包含页面冒烟（约 7 秒），
专门抓"页面根本起不来"这类故障（它真的抓到过：改坏一个方法名 ⇒ 页面白屏）。

## 4. 交付

```bash
npm run deliver                # tables/交付清单.md：必带 12 张 / 按需 1 张 / 说明 4 张
npm run pack -- --zip          # dist/agri-deliver-<日期>/ 与 .zip（约 6.3 MB）
npm run pack -- --smoke        # 打完再对着**包目录**跑冒烟（证明"打开是好的"）
```

包内包含：页面 + `data/*`（JSON/GeoJSON）+ 必带/说明表 + `交付清单.md` + `数据字典.md` + Excel。

## 5. 出问题了怎么办

| 症状 | 先跑这条 | 它会告诉你 |
|---|---|---|
| 页面白屏 / 起不来 | `npm run smoke:browser` | 页面自己的报错（7 秒） |
| 数字对不上 | `npm run data:check` | 25 条数据判据，逐项给差额 |
| 全量数据要重算 | `npm run data:all` | 从取数到交付（**需要联网**） |
| 不确定改了哪些表 | `npm run query -- --deps` | 表 + 列的运行时依赖 |

## 6. 目录

```
js/       页面（无框架，原生 DOM + Canvas）
tools/    离线工具与判据（每个 *.mjs 都是一条命令）
data/     页面数据（JSON + GeoJSON）
tables/   交付数据（CSV + Excel + 查询产物）
docs/     这页
```

## 7. 三条纪律（踩过的坑）

1. **别为了让判据变绿而改判据**：判据红了先问"数据/代码是不是真错了"；
2. **页面报错要能看到**：`smoke:browser` 已经把 `Runtime.exceptionThrown` / `console.error` 接住了，
   超时信息里会带最近 4 条页面报错 —— 别只看"超时"两个字；
3. **一份事实只写一处**：分组规则（`tools/lib/deliver-groups.mjs`）、图表标题（`buildChartData`）、
   聚合口径（`AGG_RULE`）都是"改一处、处处一致"。
