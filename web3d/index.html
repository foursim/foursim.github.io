Web 3D 渲染展示

单个页面的 three.js 场景演示：程序化生成的地形与草地（无外部模型文件）， 带雾距随相机退距、地面压暗与 SSAO 后处理。用来对比"业务数据可视化"与"实时 3D 渲染"两种 Web 表现力。

打开 3D 场景（全屏）
怎么用
  • 鼠标左键拖动 = 旋转视角，滚轮 = 推拉，右键拖动 = 平移（OrbitControls）；
  • 页面左上角是运行状态（帧率/绘制调用等），左下角是版本说明；
  • URL 参数可复现视角：?az=..&el=..&tx=..&ty=..&tz=..&z=..&ssao=0/1；
  • 返回：浏览器后退，或点顶栏「← 总导航」。
依赖说明
  • three.js r160 与所需 addon（OrbitControls / EffectComposer / RenderPass / SSAOPass / OutputPass 及其依赖） 已内置在 web3d/vendor/three/，共 13 个文件约 1.35 MB；
  • 不再引用 unpkg 等 CDN —— 断网、离线包、内网环境都能打开；
  • 因此这一页也遵守全站「运行时零外部请求」的硬线（有判据扫外链）。
场景来源：antiChaos/prebuild/wild6.html（临时借用，后续可替换为本项目的正式 3D 模块）。
